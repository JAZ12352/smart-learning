## 一、强化学习基础框架

### 1.1 马尔可夫决策过程（MDP）
强化学习的标准建模框架为元组 (S, A, P, R, γ)：
- S：状态空间（所有可能的环境状态集合）
- A：动作空间（所有可能的行动集合）
- P(s'|s,a)：状态转移概率函数
- R(s,a,s')：奖励函数
- γ ∈ [0,1)：折扣因子，控制未来奖励的现值

### 1.2 策略（Policy）
策略 π(a|s) 是状态到动作的映射：
- 确定性策略：a = π(s)
- 随机策略：π(a|s) = P(A_t=a | S_t=s)

### 1.3 价值函数
- **状态价值函数**：V^π(s) = E_π[Σ_{t=0}^∞ γ^t r_t | S_0=s]，从状态 s 出发遵循策略 π 的期望累积奖励
- **动作价值函数（Q 函数）**：Q^π(s,a) = E_π[Σ_{t=0}^∞ γ^t r_t | S_0=s, A_0=a]
- **优势函数**：A^π(s,a) = Q^π(s,a) - V^π(s)

### 1.4 Bellman 方程
- V^π(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a) [R(s,a,s') + γ V^π(s')]
- Q^π(s,a) = Σ_{s'} P(s'|s,a) [R(s,a,s') + γ Σ_{a'} π(a'|s') Q^π(s',a')]

最优价值函数满足 Bellman 最优方程：
V*(s) = max_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γ V*(s')]

## 二、Q-Learning

### 2.1 算法原理
Q-Learning（Watkins, 1989）是无模型（model-free）的离策略（off-policy）时序差分（TD）学习算法。

**更新规则**：
Q(s,a) ← Q(s,a) + α [r + γ max_{a'} Q(s',a') - Q(s,a)]

其中 α 是学习率，r + γ max_{a'} Q(s',a') 是 TD 目标。

### 2.2 收敛性
在表格型 Q-Learning 中，若每个状态-动作对被无限次访问且学习率满足 Σα = ∞, Σα² < ∞，则 Q 函数以概率1收敛到 Q*。

### 2.3 ε-贪心探索
- 以概率 ε 选择随机动作（探索）
- 以概率 1-ε 选择当前最优动作（利用）
- ε 通常从 1.0 线性衰减到 0.01

## 三、深度 Q 网络（DQN）

### 3.1 核心思想
用深度神经网络 Q(s,a;θ) 近似 Q 函数，解决表格型 Q-Learning 在高维状态空间的维度灾难。

**DeepMind DQN（2015）的两项关键创新**：

### 3.2 经验回放（Experience Replay）
将经验 (s,a,r,s') 存入回放缓冲区 D，训练时随机采样 mini-batch：
- 打破样本间的时间相关性
- 提高样本利用效率
- 缓冲区大小通常 10^5 - 10^6

### 3.3 目标网络（Target Network）
使用独立的目标网络 Q(s,a;θ^-) 计算 TD 目标，θ^- 每 C 步从 θ 复制：
- 目标：y = r + γ max_{a'} Q(s',a';θ^-)
- 损失：L(θ) = E[(y - Q(s,a;θ))²]
- 稳定训练，避免振荡

### 3.4 DQN 的局限
- 只能处理离散动作空间
- 过估计偏差（overestimation bias）：max 操作倾向于高估 Q 值
- 改进：Double DQN、Dueling DQN、Prioritized Experience Replay

## 四、策略梯度方法

### 4.1 REINFORCE 算法
直接参数化策略 π_θ(a|s)，通过梯度上升优化期望回报。

**策略梯度定理**：
∇_θ J(θ) = E_π[∇_θ log π_θ(a|s) · G_t]

其中 G_t = Σ_{k=t}^∞ γ^{k-t} r_k 是从时刻 t 开始的回报。

### 4.2 基线技术（Baseline）
引入基线 b(s) 减少方差：
∇_θ J(θ) = E_π[∇_θ log π_θ(a|s) · (G_t - b(s))]

常用基线：V(s) 的估计值。此时 G_t - V(s) 即为优势函数 A(s,a) 的估计。

### 4.3 Actor-Critic 方法
同时学习策略（Actor）和价值函数（Critic）：
- Actor：π_θ(a|s) — 决定动作
- Critic：V_φ(s) 或 Q_φ(s,a) — 评估动作好坏
- 更新：θ ← θ + α_θ ∇_θ log π_θ(a|s) · A^φ(s,a)

## 五、PPO（Proximal Policy Optimization）

### 5.1 核心思想
PPO（OpenAI, 2017）是目前最广泛使用的策略梯度算法，通过裁剪机制限制策略更新幅度。

### 5.2 PPO-Clip 目标函数
L^CLIP(θ) = E_t[min(r_t(θ)·A_t, clip(r_t(θ), 1-ε, 1+ε)·A_t)]

其中 r_t(θ) = π_θ(a_t|s_t) / π_{θ_old}(a_t|s_t) 是新旧策略的概率比，ε 通常取 0.2。

### 5.3 PPO 的优势
- 实现简单，超参数少
- 训练稳定，不易崩溃
- 并行化友好（可同时跑多个环境）
- 适用范围广：游戏、机器人控制、RLHF

### 5.4 PPO 在 RLHF 中的应用
InstructGPT/ChatGPT 使用 PPO 优化人类偏好：
- Reward Model 学习人类偏好排序
- PPO 最大化 Reward Model 得分，同时用 KL 散度约束不偏离 SFT 模型太远

## 六、多智能体强化学习（MARL）

### 6.1 核心挑战
- **非平稳性**：其他智能体也在学习，环境对每个智能体是非平稳的
- **信用分配**：团队奖励如何分配给各智能体
- **通信**：智能体间如何交换信息

### 6.2 主要方法
- **集中训练分散执行（CTDE）**：训练时用全局信息，执行时只用局部观测（QMIX、MAPPO）
- **独立 Q-Learning（IQL）**：每个智能体独立学习，简单但忽略交互
- **通信学习**：CommNet、TarMAC 等可微通信协议

## 七、强化学习在教育中的应用

### 7.1 自适应学习路径
将知识点建模为状态，学习行为建模为动作，RL 智能体根据学生实时表现选择下一个推荐知识点。

### 7.2 智能题目推荐
用 Contextual Bandit（RL 的简化版）在每次答题时选择最优难度题目，平衡探索（尝试新难度）与利用（巩固已知水平）。

### 7.3 学习时间分配
RL 优化各科目的学习时间分配，目标是最大化总体学习效果（考试成绩）。
