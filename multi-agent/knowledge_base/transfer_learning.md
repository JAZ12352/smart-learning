## 一、迁移学习基础

### 1.1 定义
迁移学习（Transfer Learning）将源域（source domain）学到的知识应用于目标域（target domain），即使两个域的数据分布不同。

**形式化**：给定源域 D_S = {(x_i^S, y_i^S)} 和目标域 D_T = {(x_i^T, y_i^T)}，迁移学习利用 D_S 的知识改善 D_T 上的学习性能。

### 1.2 迁移学习分类
| 类型 | 源域标签 | 目标域标签 | 典型方法 |
|---|---|---|---|
| 归纳迁移学习 | 有 | 有（少量） | 多任务学习、微调 |
| 直推迁移学习 | 有 | 无 | 域自适应 |
| 无监督迁移学习 | 无 | 无 | 聚类迁移、特征选择迁移 |

### 1.3 迁移的条件
- **可迁移性**：源域和目标域需共享某些可迁移的特征
- 负迁移（Negative Transfer）：源域知识损害目标域学习 → 需要检测和避免

## 二、预训练-微调范式

### 2.1 预训练阶段
在大规模无标注数据上自监督学习通用表示：

**语言模型预训练**：
- 伯特（BERT）：Masked Language Model（MLM）+ Next Sentence Prediction（NSP）
- GPT：自回归语言模型 P(x_t | x_{<t})
- T5：编码器-解码器架构，将所有任务统一为文本到文本

**视觉预训练**：
- ImageNet 预训练：在 128 万张图像上分类 1000 类
- MAE（Masked Autoencoder）：掩码 75% 图像块，重建像素

### 2.2 微调阶段
在下游任务的小规模标注数据上，调整预训练模型参数。

**全量微调**：更新所有参数。效果好但计算成本高，容易过拟合小数据集。

**参数高效微调（PEFT）**：只更新少量参数，冻结大部分预训练权重。

---

## 三、参数高效微调（PEFT）

### 3.1 LoRA（Low-Rank Adaptation）
**核心思想**：预训练权重矩阵 W 的更新量 ΔW 是低秩的。

**数学表示**：ΔW = BA，其中 B ∈ R^{d×r}, A ∈ R^{r×k}, r << min(d,k)

**可训练参数量**：从 d×k 降到 r×(d+k)，r 通常取 4-64。

**初始化**：A 用高斯随机初始化，B 初始化为零矩阵 → 训练开始时 ΔW = 0。

### 3.2 QLoRA
量化 + LoRA：将预训练权重量化为 4-bit NormalFloat（NF4），在量化基础上做 LoRA 微调。
- 显存需求：7B 模型从 ~28GB（全量 FP16）降到 ~6GB（QLoRA 4-bit）
- 效果：几乎无损，略低于全量微调

### 3.3 Adapter Tuning
在 Transformer 每层插入小型瓶颈网络：
- 下投影：W_down ∈ R^{d×m}（m << d）
- 非线性激活：ReLU 或 GELU
- 上投影：W_up ∈ R^{m×d}

可训练参数量：每层 2×d×m，m 通常取 d/64。

### 3.4 Prompt Tuning
在输入嵌入前拼接可学习的连续 prompt 向量 P ∈ R^{l×d}，只训练 P，冻结模型所有参数。
- 适合大模型：参数量极小（l×d，l 通常 10-100）
- 效果：模型越大，prompt tuning 越接近全量微调

## 四、领域自适应（Domain Adaptation）

### 4.1 对抗域适应
引入域判别器 D，训练特征提取器 G 使 D 无法区分源域和目标域特征。
- 损失：L = L_task(G(x_S), y_S) - λ L_domain(D(G(x_S)), D(G(x_T)))
- 目标：G 生成域不变特征

### 4.2 最大均值差异（MMD）
最小化源域和目标域特征分布在再生核希尔伯特空间（RKHS）中的距离：
MMD² = ||μ_S - μ_T||²_H = ||E[φ(x_S)] - E[φ(x_T)]||²

### 4.3 对比学习域适应
通过对比损失拉近同类别跨域样本、推远不同类别样本。

## 五、多任务学习

### 5.1 硬参数共享
所有任务共享底层参数，顶层各任务独立参数。
- 降低过拟合风险（多个任务提供正则化）
- 计算效率高（共享层只需前向传播一次）

### 5.2 软参数共享
每个任务有独立参数，但添加正则项约束参数相似性：
L = Σ_t L_task(t) + λ Σ_{t1≠t2} ||W_{t1} - W_{t2}||²

### 5.3 任务关系发现
自动发现任务间关系的方法：
- N(Task)：基于任务梯度相似度构建任务图
- 硬件资源调度：在共享层和任务特定层间动态分配参数

## 六、预训练模型规模与性能

### 6.1 涌现能力（Emergent Abilities）
当模型规模超过某阈值时突然出现的能力（Wei et al., 2022）：
- Chain-of-Thought 推理：>100B 参数时显著提升
- Few-shot 学习：>10B 参数时明显优于随机

### 6.2 缩放定律（Scaling Laws）
Kaplan et al. (2020) 发现：模型性能（loss）与参数量 N、数据量 D、计算量 C 呈幂律关系：
L(N) ∝ N^{-α_N}，α_N ≈ 0.076

## 七、迁移学习在教育中的应用

### 7.1 跨领域知识迁移
将通用预训练模型迁移到教育领域（如考试题、教案），提升教育AI的语义理解能力。

### 7.2 少样本学习
利用预训练模型的 few-shot 能力，仅需少量标注教育样本即可适应新学科或新题型。

### 7.3 多语言教育内容
利用多语言预训练模型（mBERT、XLM-R）将教育内容自动翻译/适配到不同语言。
