# 因果推断与可解释人工智能（垂直领域知识库切片 · XAI 分册）

> 用途：为 RAG 检索提供因果推断和可解释AI的权威定义、核心方法与评估标准，支撑事实性核验。
> 覆盖范围：因果推断框架、SHAP、LIME、注意力可视化、反事实解释。

## 一、因果推断基础

### 1.1 相关≠因果
"相关不等于因果"是因果推断的核心原则。两个变量相关可能因为：
- 直接因果：A → B
- 共同原因（混杂）：C → A, C → B
- 选择偏差：样本非随机选择
- 反向因果：B → A

### 1.2 因果推断框架：潜在结果（Rubin Causal Model）
- 个体处理效应（ITE）：ITE_i = Y_i(1) - Y_i(0)
  - Y_i(1)：个体 i 接受处理的结果
  - Y_i(0)：个体 i 未接受处理的结果
- 平均处理效应（ATE）：ATE = E[Y(1) - Y(0)]
- **因果推断的根本问题**：同一单位不能同时观测到处理和未处理结果（反事实）

### 1.3 因果推断框架：Pearl 因果图（DAG）
- 节点：变量
- 有向边：直接因果关系
- 后门准则（Backdoor Criterion）：识别因果效应的充分条件
  - 后门路径：从处理到结果的非因果路径
  - 后门调整：控制所有后门路径上的混杂变量

### 1.4 因果推断方法
| 方法 | 核心思想 | 适用场景 |
|---|---|---|
| 倾向得分匹配（PSM） | 控制可观测混杂 | 观察性研究 |
| 工具变量（IV） | 利用外生变量 | 存在不可观测混杂 |
| 断点回归（RDD） | 利用分配阈值 | 政策评估 |
| 双重差分（DID） | 比较处理组和对照组的变化趋势 | 面板数据 |

## 二、SHAP（SHapley Additive exPlanations）

### 2.1 Shapley 值基础
Shapley 值源自合作博弈论，为每个玩家分配公平的收益份额。

**数学定义**：对于特征子集 S，特征 i 的 Shapley 值：
φ_i = Σ_{S⊆N\{i}} |S|!(|N|-|S|-1)!/|N|! · [v(S∪{i}) - v(S)]

其中 v(S) 是特征子集 S 的边际贡献，N 是所有特征集合。

### 2.2 SHAP 的三种变体
| 变体 | 计算方式 | 适用场景 |
|---|---|---|
| KernelSHAP | 基于 LIME 的加权回归 | 模型无关（黑盒） |
| TreeSHAP | 决策树递归计算 | 树模型（精确、高效） |
| DeepSHAP | 基于 DeepLIFT 的反向传播 | 深度学习模型 |

### 2.3 SHAP 的性质
- **局部可加性**：预测值 = 基准值 + Σ φ_i（每个特征的贡献之和等于预测值与基准值的差）
- **对称性**：贡献相同的特征获得相同 Shapley 值
- **效率性**：所有特征的 Shapley 值之和等于模型输出与基准输出之差

### 2.4 SHAP 可视化
- **力图（Force Plot）**：展示每个特征对预测的正/负贡献
- **蜂群图（Beeswarm Plot）**：全局特征重要性 + 方向
- **依赖图（Dependence Plot）**：特征值与 SHAP 值的关系

## 三、LIME（Local Interpretable Model-agnostic Explanations）

### 3.1 核心思想
用简单的可解释模型（如线性模型）局部近似复杂黑盒模型。

**步骤**：
1. 在待解释样本 x 附近扰动生成样本
2. 用黑盒模型对扰动样本预测
3. 以距离为权重，训练局部线性模型
4. 用局部线性模型的系数作为解释

### 3.2 LIME 的数学形式
对于文本分类：在 x 的邻域内采样，损失函数：
ξ(x) = Σ_{z∈扰动样本} π_x(z) · (f(z) - g(z))²

其中 π_x(z) = exp(-D(x,z)²/σ²) 是距离权重，g 是局部解释模型。

### 3.3 LIME 的局限
- 解释不稳定：多次运行可能得到不同解释
- 扰动策略影响结果：文本和图像的扰动方式差异大
- 局部近似的保真度难以量化

## 四、注意力可视化

### 4.1 自注意力权重
Transformer 的自注意力权重反映 token 间的交互强度。

**可视化方法**：热力图，横纵轴为 token，颜色深浅为注意力分数。

### 4.2 注意力≠解释
Jain & Wallace (2019) 指出注意力权重不一定等于特征重要性：
- 注意力分布可能与梯度重要性不一致
- 多头注意力使单个头的权重难以解释
- 替代方案：梯度×输入（Grad-CAM for NLP）

### 4.3 改进方法
- **注意力流（Attention Flow）**：考虑所有路径的最短路径注意力
- **注意力 rollout**：逐层累积注意力权重
- **Integrated Gradients**：沿基线到输入的路径积分梯度

## 五、反事实解释（Counterfactual Explanation）

### 5.1 定义
反事实解释回答"需要改变什么才能使预测结果不同？"

**示例**：贷款被拒 → "如果你的年收入增加 5000 元且信用记录增加 2 条良好记录，贷款将被批准。"

### 5.2 生成方法
- **优化方法**：最小化 L = 距离(x, x') + λ·I(f(x')≠f(x))
  - Wachter et al. (2017)：用梯度下降找到最小改变的反事实
- **搜索方法**：在数据集中搜索最近的反事实样本
- **Growing Spheres**：逐步扩大搜索范围找到最近反事实

### 5.3 反事实解释的性质
- **有效性**：改变后的预测确实不同
- **接近性**：反事实与原始输入尽量接近
- **可行性**：改变在现实世界中可实现（如收入可以增加，性别不能改变）
- **多样性**：提供多个不同的反事实选项

## 六、可解释AI在教育中的应用

### 6.1 学习预测解释
用 SHAP 解释为什么系统预测某学生会不及格（如"出勤率低"贡献最大）。

### 6.2 推荐系统解释
向学生推荐某课程时，给出推荐理由（如"与你学过的课程A在知识点B上高度相关"）。

### 6.3 评分系统透明性
对学生作业自动评分给出详细解释，说明扣分原因和改进方向。

### 6.4 公平性审计
用 SHAP 检测评分系统是否存在性别/年龄偏差（如相同质量的作业，女性学生得分偏低）。
