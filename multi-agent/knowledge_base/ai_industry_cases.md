# AI 行业应用与岗位技能规范（垂直领域知识库切片 · 行业分册）

> 用途：面向企业内训、转岗培训场景的行业落地知识与岗位能力标准，供 RAG 检索增强生成使用。
> 覆盖范围：制造业质检、工业互联网预测性维护、智能客服、推荐系统、金融风控五大场景的落地方案与岗位规范。
> 适用对象：AI 解决方案工程师、算法工程师、实施工程师、企业培训部门、转岗人员。

---

## 一、制造业视觉质检

### 1.1 业务流程与系统架构
标准五步流程：图像采集 → 预处理 → 缺陷检测模型 → 判定与分级 → MES 系统联动。
- 采集：工业相机 + 环形/背光源；分辨率按最小缺陷尺寸的 3～5 倍选取（要检出 0.1mm 缺陷，至少需要能分辨 0.02mm 的镜头组合）。
- 预处理：几何校正、光照均衡（CLAHE）、去噪；产线振动场景需硬件触发拍照而非软触发。

### 1.2 模型选型规范
- 缺陷样本充足（每类 ≥500 张）：YOLOv8/YOLO11 目标检测，单帧推理 <30ms 满足产线节拍。
- 缺陷样本稀缺（每类 <100 张）：无监督异常检测（PatchCore、PaDiM），只需正常样本即可训练。
- 细粒度外观要求高：分割模型（U-Net/DeepLabV3+）输出缺陷面积、周长等量化指标。
- 产线判定规则：模型输出置信度分三档——高置信自动判定（阈值如 >0.9）、中置信人工复检（0.5～0.9）、低置信放行并记录。误杀率与漏检率按业务损失定权，一般漏检成本远高于误杀，阈值向低漏检偏移。

### 1.3 上线验收指标
- 与人工质检员对拍 ≥2 万张：模型漏检率 ≤人工水平、过杀率 ≤3×人工水平方可切换。
- 连续 4 周现场运行：误报率波动 <20%、无 P0 级停线事故。
- ROI 核算模板：年节省人力成本 + 减少流出损失 −（设备折旧 + 运维）>0 视为可立项。

## 二、工业互联网预测性维护

### 2.1 数据基础
- 传感数据：振动（加速度计，采样率 ≥10kHz 用于轴承故障）、温度、电流、声学。
- 时序特征工程：时域（RMS、峰值因子、峭度）、频域（FFT 频带能量）、时频域（小波包能量熵）。轴承故障特征频率计算：外圈 BPFO、内圈 BPFI、滚动体 BSF，由转速与几何参数推导。
- 数据基础设施：OPC UA/MQTT 采集 → 时序数据库（InfluxDB/TDengine）→ 特征平台 → 模型服务。

### 2.2 建模方法阶梯
1. 规则基线：阈值报警（温度/RMS 超限），必须先行部署作为兜底。
2. 健康指标（HI）构建：正常工况下训练自编码器，重构误差作为健康分数，超阈值预警。
3. 剩余寿命（RUL）预测：LSTM/Transformer 回归剩余使用寿命，退化数据充足时使用；C-MAPSS 是标准基准数据集。
4. 冷启动方案：无故障历史时用物理模型 + 相似设备迁移学习。

### 2.3 落地要点
- 报警精确率优先：产线最反感狼来了，误报率需 <每周 1 次；建议多传感器证据融合后再报警。
- 维护决策闭环：预警 → 工单生成 → 备件预占 → 维护后标注反馈，形成数据飞轮。
- 典型效益参考：降低非计划停机 30%～50%、延长设备寿命 20%～40%（麦肯锡/GE 数字化工厂公开报告区间）。

## 三、智能客服与对话系统

### 3.1 系统分层
- 意图识别层：NLU 分类（常见意图 30～200 个），BERT 微调准确率目标 ≥92%；低于阈值走澄清话术。
- 知识问答层：FAQ 精准匹配（向量召回 + 重排，Top1 相似度 >0.85 直接命中）；文档问答走 RAG。
- 任务型对话层：槽位填充 + 对话状态管理 + API 调用（查订单/改地址），关键操作需二次确认。
- 人机协作层：机器人置信度 <阈值自动转人工，转接时携带完整对话摘要。

### 3.2 关键运营指标
| 指标 | 定义 | 达标线 |
|---|---|---|
| 问题解决率（FCR） | 无人工介入解决比例 | ≥70%（售后场景 ≥55%） |
| 转人工率 | 转人工会话占比 | ≤25% |
| 意图识别准确率 | 测试集 Top1 | ≥92% |
| 平均响应时长 | 用户发问到首响 | <2s |
| 满意度 CSAT | 会话结束后评分 | ≥4.2/5 |

### 3.3 知识库治理
- FAQ 更新机制：每周分析未命中的 top 问题，新增/改写 FAQ ≥20 条。
- 答案审核流程：业务方编写 → 知识运营初审 → 法务合规复审（涉及承诺、赔付话术）→ 发布。
- 敏感边界：医疗建议、投资建议、法律结论类问题必须使用免责话术并引导专业渠道。

## 四、推荐系统

### 4.1 架构分层
召回（多路：协同过滤/向量 ANN/热门/新品，各路几百条）→ 粗排（轻量双塔，千→百）→ 精排（DIN/SIM 等 CTR 模型，百→几十）→ 重排（多样性 MMR、业务规则、去重打散）。

### 4.2 核心技术与评估
- 协同过滤：ItemCF 适合 item 数少且稳定的场景（电商），UserCF 适合新闻社交；相似度用余弦并做流行度惩罚（α-norm）抑制马太效应。
- 向量召回：双塔模型（用户塔/物品塔）离线建 ANN 索引（HNSW/Faiss），在线毫秒级检索。
- CTR 精排：特征交叉从 FM → DeepFM → DIN（注意力聚合行为序列）；训练样本负采样比例与线上分布一致。
- 离线指标 AUC ≥0.75 才有上线价值；线上看 CTR、人均停留时长、转化率；必须做 A/B 实验（分流哈希一致、实验周期 ≥2 周、样本量按 MDE 预估）。

### 4.3 工程红线
- 新品/新用户冷启动必须有专属通道（内容标签召回 + 探索流量保底 5%）。
- 多样性与生态指标：类目分散度、供给侧覆盖率纳入考核，防止信息茧房与头部挤压。
- 合规：推荐解释（"因为你浏览过…"）、一键关闭个性化推荐（算法备案要求）。

## 五、金融风控

### 5.1 申请评分卡（A 卡）标准流程
1. 样本定义：观察期 ≥6 个月、表现期 6～12 个月；好坏定义（如 M2+ 为坏客户）需业务与风险部联签。
2. 特征分箱：WOE 编码 + IV 筛选（IV<0.02 剔除、>0.5 关注泄漏）；单调性约束保证可解释。
3. 逻辑回归建模：入变量 ≤15 个、VIF<5、系数符号与业务直觉一致。
4. 评分转换：Score = A − B×ln(odds)，B=PDO/ln2（PDO 常 20～40 分翻倍）。
5. 验收：KS ≥0.3、AUC ≥0.7、PSI<0.1（评分稳定性）；通过率/坏账率权衡找最优切点。

### 5.2 反欺诈与机器学习风控
- 规则引擎兜底（黑名单、频次、设备指纹）实时拦截；模型层用 GBDT/XGBoost 处理非线性与交互。
- 图风控：团伙欺诈用关系图谱（共享设备/手机号/地址社区发现 Louvain）。
- 极端不平衡处理：xgboost 设 scale_pos_weight≈负正比、或 focal loss；评价指标用 PR-AUC 而非 Accuracy。
- 监管合规硬约束：拒绝必须给理由（EAD/AAD 类原因码）；模型需通过可解释性审查（SHAP 值报告）；不得直接使用民族、性别等敏感特征及其代理变量。

## 六、岗位技能矩阵与培训路径

### 6.1 AI 岗位技能矩阵（企业内训定级参考）
| 岗位 | 必备技能 | 加分技能 | 定级锚点 |
|---|---|---|---|
| AI 应用开发工程师 | Python、API 集成、RAG、Prompt 工程 | Agent 编排、前端可视化 | 能独立交付一个 LLM 应用 |
| 算法工程师 | 机器学习理论、PyTorch、调参 | 论文复现、竞赛成绩 | 能在基准上复现并改进 SOTA |
| MLOps 工程师 | Docker/K8s、CI/CD、监控 | GPU 调度、特征平台 | 模型发布全自动化 |
| 数据标注与知识运营 | 标注规范、质检、知识库维护 | 标注平台二次开发 | Kappa≥0.7 的团队质控能力 |
| AI 解决方案工程师 | 行业 know-how、POC 设计、ROI 核算 | 售前演示、投标 | 独立完成 POC 到签约 |

### 6.2 转岗培训标准路径（零基础 → 上岗，12 周）
- 第 1～2 周：Python 基础 + SQL（每天 2 小时编码练习）。
- 第 3～4 周：机器学习基础（sklearn 全流程 + Kaggle 入门赛）。
- 第 5～8 周：方向深耕（视觉/LLM 应用/数据分析三选一），产出 1 个可展示项目。
- 第 9～10 周：工程化补齐（Docker、FastAPI、Git 协作、单元测试）。
- 第 11～12 周：综合实战（真实脱敏业务数据 + 验收答辩），通过标准：项目端到端可运行 + 指标达标 + 15 分钟技术答辩。

### 6.3 内训课程设计原则
- 721 法则：70% 实操、20% 同伴互评与 code review、10% 讲授。
- 每个知识点配"讲义 + 可运行示例 + 分阶测试题"三件套（对应本系统的三类资源形态）。
- 结业双证：笔试（知识掌握 ≥80 分）+ 实战（项目评审通过）。

## 附：行业术语速查
- MES：制造执行系统；节拍（Takt Time）：产线两件产品的间隔时间上限。
- PSI：群体稳定性指数，>0.25 表示分布显著漂移。
- WOE/IV：证据权重/信息值，评分卡特征筛选标准。
- FCR：首次问题解决率；A/B 实验最小样本量由基线转化率与最小可检测效应（MDE）决定。
