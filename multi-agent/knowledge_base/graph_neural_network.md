## 一、图结构基础

### 1.1 图的数学表示
图 G = (V, E)，其中：
- V：节点集合，|V| = n
- E：边集合，|E| = m
- 邻接矩阵 A ∈ R^{n×n}：A_{ij} = 1 表示节点 i 和 j 之间有边
- 节点特征矩阵 X ∈ R^{n×d}：第 i 行是节点 i 的 d 维特征向量

### 1.2 图的类型
| 类型 | 特征 | 示例 |
|---|---|---|
| 无向图 | 边无方向 | 社交网络 |
| 有向图 | 边有方向 | 引用网络、网页链接 |
| 异构图 | 多种节点/边类型 | 知识图谱 |
| 时序图 | 节点/边随时间变化 | 交通流网络 |

### 1.3 图的邻居聚合
GNN 的核心操作：每个节点聚合其邻居的信息来更新自身表示。

**消息传递框架（Message Passing Neural Network, MPNN）**：
1. **消息函数**：m_v = Σ_{u∈N(v)} M(h_v, h_u, e_{vu})
2. **聚合函数**：h_v' = U(h_v, m_v)
3. **更新函数**：h_v' = σ(W · AGG({h_u : u ∈ N(v)} ∪ {h_v}))

其中 N(v) 是节点 v 的邻居集合，M 是消息函数，U 是更新函数。

## 二、图卷积网络（GCN）

### 2.1 核心公式
GCN（Kipf & Welling, 2017）的逐层传播规则：

H^{(l+1)} = σ(D̃^{-1/2} Ã D̃^{-1/2} H^{(l)} W^{(l)})

其中：
- Ã = A + I_n（加自环的邻接矩阵）
- D̃ = Σ_j Ã_{ij}（度矩阵）
- W^{(l)}：可训练的权重矩阵
- σ：激活函数（通常 ReLU）

### 2.2 单层 GCN 的含义
对节点 i，第 l+1 层的表示是：
h_i^{(l+1)} = σ(Σ_{j∈N(i)∪{i}} (1/√(d_i·d_j)) · h_j^{(l)} · W^{(l)})

即：归一化地聚合自身和邻居的特征，再线性变换 + 非线性激活。

### 2.3 GCN 的局限
- **过平滑（Over-smoothing）**：层数过多（>3-4层）时所有节点表示趋同
- **转导式（Transductive）**：需要完整的图结构（包括测试节点的边），不能直接用于归纳新节点
- **一阶近似**：只聚合直接邻居，无法捕获多跳关系

## 三、图注意力网络（GAT）

### 3.1 核心创新：注意力权重
GAT（Veličković et al., 2018）为每条边学习注意力权重，而非均匀聚合。

**注意力系数计算**：
α_{ij} = softmax_j(LeakyReLU(a^T [Wh_i ∥ Wh_j]))

其中：
- W：可训练的线性变换矩阵
- a：可训练的注意力向量
- ∥：拼接操作
- softmax_j：对节点 i 的所有邻居 j 做归一化

### 3.2 多头注意力
K 个独立的注意力头，各自计算后拼接或平均：
h_i' = ∥_{k=1}^K σ(Σ_{j∈N(i)} α_{ij}^k · W^k · h_j)
或 h_i' = σ((1/K) Σ_{k=1}^K Σ_{j∈N(i)} α_{ij}^k · W^k · h_j)

### 3.3 GAT vs GCN
| 维度 | GCN | GAT |
|---|---|---|
| 邻居权重 | 固定（基于度数） | 自适应（注意力学习） |
| 表达能力 | 较弱 | 较强（可区分不同邻居重要性） |
| 计算开销 | 低 | 中（需要计算注意力） |
| 可解释性 | 无 | 注意力权重提供可解释性 |

## 四、GraphSAGE

### 4.1 核心思想：归纳式学习
GraphSAGE（Hamilton et al., 2017）通过采样和聚合邻居来生成新节点的嵌入，支持归纳学习（处理训练时未见过的节点）。

**算法**：
1. 采样：对每个节点，随机选择 K 个邻居（固定数量）
2. 聚合：h_N(v) = AGG({h_u : u ∈ S(v)})，S(v) 是采样后的邻居集合
3. 更新：h_v = σ(W · [h_v ∥ h_N(v)])

### 4.2 聚合函数选择
- **均值聚合**：h_N(v) = mean({h_u})
- **LSTM 聚合**：h_N(v) = LSTM(shuffle({h_u}))
- **池化聚合**：h_N(v) = max({σ(W_pool · h_u + b_pool)})

### 4.3 GraphSAGE 的优势
- 归纳式：可为新节点生成嵌入（无需重新训练）
- 可扩展：采样使计算复杂度可控
- 灵活：聚合函数可替换

## 五、图分类与图级表示

### 5.1 图池化（Graph Pooling）
将节点级表示聚合为图级表示：
- **全局池化**：h_G = READOUT({h_v : v ∈ V})，READOUT 可以是 mean/max/sum
- **层次池化**：逐步粗化图结构（DiffPool、MinCutPool）

### 5.2 图核方法（Graph Kernels）
- **Weisfeiler-Lehman 核**：迭代地聚合邻居标签，比较子树结构
- **随机游走核**：计算两条随机游走路径的匹配程度
- **子图核**：枚举所有子图并比较

## 六、知识图谱嵌入

### 6.1 任务定义
将知识图谱中的实体和关系映射到低维向量空间，使嵌入能捕获图谱的结构和语义信息。

### 6.2 经典方法
| 方法 | 评分函数 | 特点 |
|---|---|---|
| TransE | d(h+r, t) = ||h+r-t|| | 简单高效，一对多关系弱 |
| TransR | d(h,r,t) = ||h·M_r + r - t·M_r| | 关系特定投影空间 |
| DistMult | <h, r, t> = Σ h_i·r_i·t_i | 对称关系好，非对称弱 |
| ComplEx | Re(<h, r, conj(t)>) | 复数空间，支持非对称 |
| RotatE | ||h∘r - t|| | 旋转模型，支持组合推理 |

### 6.3 链接预测评估
- 任务：给定 (h, r, ?) 或 (?, r, t)，预测缺失实体
- 指标：MRR（Mean Reciprocal Rank）、Hits@1/3/10
- 典型结果：FB15k-237 上 RotatE MRR ≈ 0.33，Hits@10 ≈ 0.53

## 七、GNN 在教育中的应用

### 7.1 知识图谱推理
用 GNN 在知识点图谱上做链接预测，发现隐含的知识点关联。

### 7.2 学生关系建模
将学生互动建模为图，用 GNN 捕获学习社区结构，辅助协作学习推荐。

### 7.3 题目相似度
将题目中的概念建模为图结构，用 GNN 计算题目间的语义相似度，支持组卷和查重。
