## 一、联邦学习基础

### 1.1 定义
联邦学习（Federated Learning, McMahan et al., 2017）是一种分布式机器学习范式：多个参与方在不共享原始数据的情况下协作训练共享模型。

**核心约束**：原始数据不出本地（data stays on device）。

### 1.2 联邦学习分类
| 类型 | 数据划分方式 | 典型场景 |
|---|---|---|
| 横向联邦学习（HFL） | 样本不同，特征相同 | 多家银行联合训练信用模型 |
| 纵向联邦学习（VFL） | 样本相同，特征不同 | 银行+电商联合建模 |
| 联邦迁移学习 | 样本和特征都不同 | 跨领域数据协作 |

### 1.3 联邦学习 vs 分布式学习
| 维度 | 联邦学习 | 分布式学习 |
|---|---|---|
| 数据分布 | 非独立同分布（Non-IID） | 独立同分布（IID） |
| 通信瓶颈 | 高（移动设备带宽有限） | 低（数据中心内网） |
| 隐私要求 | 高（原始数据不共享） | 低（数据可集中） |
| 可靠性 | 参与方可随时退出 | 节点稳定 |

## 二、FedAvg（Federated Averaging）

### 2.1 算法流程
FedAvg 是最经典的联邦学习算法（McMahan et al., 2017）：

1. **服务器初始化**：广播全局模型参数 w_0
2. **客户端本地训练**：
   - 每个客户端 k 从本地数据中采样 mini-batch
   - 用 SGD 更新本地模型：w_k^{t+1} = w_k^t - η ∇L(w_k^t; B_k)
   - 迭代 E 个 epoch
3. **服务器聚合**：
   - 收集各客户端更新后的模型 w_k^{t+1}
   - 加权平均：w^{t+1} = Σ_k (n_k / n) · w_k^{t+1}
   - n_k 是客户端 k 的样本数，n 是总样本数

### 2.2 收敛性
FedAvg 在 Non-IID 数据上的收敛速度比 FedSGD 慢，但通信轮次大幅减少（E>1 时）。

**收敛率**：O(1/(TEK)) + O(σ²/KE) + O(E²/T)，其中 T 是通信轮次，E 是本地 epoch 数。

### 2.3 Non-IID 问题
当客户端数据分布不同时，FedAvg 的收敛速度和最终性能下降：
- **客户端漂移（Client Drift）**：本地训练使模型偏离全局最优
- 解决方法：SCAFFOLD（控制变量）、FedProx（近端项约束）

## 三、差分隐私（Differential Privacy）

### 3.1 定义
差分隐私（DP）提供严格的隐私保证：单条记录的加入或删除对输出分布的影响有界。

**（ε,δ)-差分隐私**：
Pr[M(D) ∈ S] ≤ e^ε · Pr[M(D') ∈ S] + δ

其中 D 和 D' 是相差一条记录的数据集，M 是随机化机制。

### 3.2 DP-SGD（差分隐私随机梯度下降）
**步骤**：
1. 梯度裁剪：g̃_i = g_i / max(1, ||g_i||₂ / C)（L2 范数裁剪到阈值 C）
2. 噪声注入：g̃ = (1/n)(Σ_i g̃_i + N(0, σ²C²I))
3. 用噪声梯度更新模型

**隐私预算**：由 (ε,δ) 量化，ε 越小隐私保护越强，但模型效用越差。

### 3.3 隐私会计（Privacy Accounting）
跟踪累计隐私消耗：
- **组合定理**：k 次查询的总隐私预算 ≤ k·ε
- **矩会计（Moments Accountant）**：更紧的界，通过 moments generating function 计算
- **Rényi DP**：更灵活的隐私定义

## 四、安全聚合（Secure Aggregation）

### 4.1 目的
防止服务器看到各客户端的模型更新（即使服务器不可信）。

### 4.2 朴素方案
- **同态加密**：客户端加密模型更新，服务器在密文上做加法聚合
  - 问题：计算开销大（~100-1000× 明文运算）
- **秘密共享**：将模型更新拆分为多份，分散存储

### 4.3 实用方案：掩码 + Diffie-Hellman
1. 客户端 i 随机生成掩码 m_{ij}，满足 Σ_i m_{ij} = 0
2. 客户端 i 发送 Δw_i + m_{ij} 给客户端 j
3. 服务器只看到聚合后的 Δw = Σ_i Δw_i（掩码相互抵消）

### 4.4 安全性保证
- 半诚实模型（Honest-but-Curious）：服务器遵循协议但试图推断隐私
- 恶意模型（Malicious）：服务器可能偏离协议 → 需要更重的密码学原语

## 五、通信优化

### 5.1 梯度压缩
- Top-K 稀疏化：只传输梯度绝对值最大的 K 个分量
- 量化：将 32-bit 浮点数压缩为 1-8 bit
- 误差反馈：累积未传输的梯度到下一轮

### 5.2 异步更新
- 客户端不等待其他客户端完成，随时上传更新
- 优势：减少空闲等待
- 劣势：stale updates 可能降低收敛速度

### 5.3 客户端选择
- 每轮随机选择部分客户端参与（如全部客户端的 10%）
- 降低通信开销，同时保持统计效率

## 六、联邦学习的应用场景

### 6.1 跨机构金融风控
多家银行在不共享客户数据的前提下联合训练反欺诈模型。

### 6.2 医疗数据协作
多家医院联合训练疾病预测模型，遵守 HIPAA 等隐私法规。

### 6.3 移动设备输入预测
Google 在 Gboard 中使用联邦学习训练下一词预测模型，原始输入数据不离开手机。
