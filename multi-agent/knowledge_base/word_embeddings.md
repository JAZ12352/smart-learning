## 一、词向量基础概念

### 1.1 什么是词向量
词向量（Word Embedding）是将自然语言中的词语映射到低维连续向量空间的数学表示方法。核心假设：语义相似的词在向量空间中距离相近。

**数学定义**：给定词表 V，词向量函数 f: V → R^d，将每个词 w 映射为 d 维实数向量 v_w ∈ R^d。d 通常取 100-300。

### 1.2 词向量的核心属性
- **语义相似性**：余弦相似度 sim(v_w1, v_w2) = (v_w1 · v_w2) / (||v_w1|| × ||v_w2||) 反映语义距离
- **线性类比关系**：v_king - v_man + v_woman ≈ v_queen，这是词向量最著名的性质
- **维度独立性**：不同维度捕获不同语义特征（如性别、时态、领域）

## 二、Word2Vec

### 2.1 CBOW（Continuous Bag of Words）
由上下文词预测中心词。给定窗口大小 c 内的上下文词 {w_{t-c}, ..., w_{t-1}, w_{t+1}, ..., w_{t+c}}，预测中心词 w_t。

**模型结构**：
- 输入层：上下文词的 one-hot 向量（维度 |V|）
- 隐藏层：对上下文词向量取平均，h = (1/2c) Σ v_{w_i}，维度 d
- 输出层：Softmax 分类，P(w_t | context) = exp(u_{w_t}^T h) / Σ_{w∈V} exp(u_w^T h)

**训练目标**：最大化对数似然 L = Σ log P(w_t | context)

**负采样优化**：将 Softmax 的 O(|V|) 降低到 O(K)，K 通常取 5-20。目标改为区分真实上下文对与 K 个随机噪声对。

### 2.2 Skip-gram
由中心词预测上下文词，与 CBOW 方向相反。

**模型结构**：输入中心词向量 v_w_t，预测窗口内每个上下文词 w_{t+j}（|j|≤c）。

**训练目标**：L = Σ_{-c≤j≤c, j≠0} log P(w_{t+j} | w_t)

**Skip-gram 优势**：在小数据集和罕见词上表现优于 CBOW（因为每个词作为中心词时产生多个训练样本）。

### 2.3 Word2Vec 训练细节
- 向量初始化：随机初始化（如均匀分布 U(-0.5/d, 0.5/d)）
- 学习率：初始 0.025，线性衰减至最小 0.0001
- 窗口大小：Skip-gram 通常 5，CBOW 通常 8
- 下采样：高频词（如"的"、"是"）以概率 p = 1 - √(t/f) 下采样，f 为词频，t 通常取 10^-3

## 三、GloVe（Global Vectors for Word Representation）

### 3.1 核心思想
GloVe 结合了全局统计（LSA）和局部上下文（Word2Vec）的优点。核心观察：词向量应编码共现概率的比值信息。

**共现矩阵 X**：X_ij = 词 i 和词 j 在上下文窗口内共现的次数。

**共现概率比值**：P(k|i) = X_ik / X_i，其中 k 是上下文词，i 是焦点词。
- 比值 P(k|ice)/P(k|steam) 能区分语义：当 k=solid 时比值大，k=gas 时比值小，k=water 时比值接近1。

### 3.2 损失函数
L = Σ_{i,j=1}^{|V|} f(X_ij) (v_i^T v_j + b_i + b_j - log X_ij)^2

其中权重函数 f(x) = (x/x_max)^α if x < x_max else 1，α 通常取 0.75，x_max 取 100。

### 3.3 GloVe 与 Word2Vec 的区别
| 维度 | Word2Vec | GloVe |
|---|---|---|
| 训练方式 | 局部上下文窗口（预测任务） | 全局共现矩阵分解（回归任务） |
| 信息利用 | 只用局部共现 | 用全局共现统计 |
| 训练效率 | 较快（SGD） | 较慢（需要构建共现矩阵） |
| 理论基础 | 预测式（Predictive） | 计数式（Count-based） |

## 四、FastText

### 4.1 核心创新：子词信息
FastText（Facebook, 2016）在 Word2Vec 基础上引入子词（subword）n-gram 信息。

**向量表示**：v_w = Σ_{g∈G(w)} z_g，其中 G(w) 是词 w 的所有字符 n-gram 集合（n 通常取 3-6），z_g 是 n-gram 向量。

**示例**：词 "where" 的 3-gram 集合 = {<wh, whe, her, ere, re>}（< 和 > 表示词边界）

**优势**：
- 能处理未登录词（OOV）：通过子词向量组合表示
- 对形态丰富的语言（德语、土耳其语、中文）效果更好
- 能捕获词形相似性（如 "cat" 和 "cats" 共享子词）

## 五、上下文词向量（Contextualized Embeddings）

### 5.1 静态词向量的局限
Word2Vec/GloVe/FastText 为每个词生成固定向量，无法处理一词多义。

**示例**：bank 在 "river bank" 和 "bank account" 中语义不同，但静态词向量相同。

### 5.2 ELMo（Embeddings from Language Models, 2018）
使用双向 LSTM 语言模型，为每个词生成依赖上下文的表示。

**向量计算**：h_k = Σ_{j=0}^{L} γ_j h_{k,j}，其中 h_{k,j} 是第 j 层 LSTM 在位置 k 的隐状态，γ_j 是可学习的层权重。

### 5.3 BERT 嵌入
BERT（2018）使用 Transformer 编码器生成上下文词向量。

**向量来源**：BERT 的最后一层（或倒数第二层）输出作为词向量，每个词的向量取决于完整句子上下文。

**BERT 嵌入维度**：base 版 768 维，large 版 1024 维。

## 六、词向量评估

### 6.1 内在评估（Intrinsic Evaluation）
- **类比任务（Analogy Task）**：v_a - v_b + v_c ≈ v_d，计算准确率
  - 语义类比：king:queen :: man:woman
  - 语法类比：good:best :: bad:worst
- **相似度任务**：计算词对余弦相似度与人工评分的相关性（Spearman ρ）
  - 标准数据集：WordSim-353、SimLex-999

### 6.2 外在评估（Extrinsic Evaluation）
将词向量作为下游任务的特征，评估任务性能提升：
- 文本分类准确率
- 命名实体识别 F1
- 情感分析 AUC

### 6.3 典型评估结果
| 模型 | 类比准确率（语义） | 相关性（WS-353） |
|---|---|---|
| Word2Vec Skip-gram | ~75% | 0.65 |
| GloVe 300d | ~78% | 0.68 |
| FastText 300d | ~80% | 0.67 |
| BERT-base | ~85% | 0.72 |

## 七、词向量在教育系统中的应用

### 7.1 知识点语义关联
用词向量计算知识点间的语义距离，辅助知识图谱构建和知识点推荐。

### 7.2 个性化学习路径
基于学生历史学习记录的词向量表示，推荐语义相近的下一个学习内容。

### 7.3 作业/考试自动评分
用词向量计算学生答案与标准答案的语义相似度，支持开放题自动评分。
